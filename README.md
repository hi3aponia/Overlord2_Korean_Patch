스팀(Steam) 버전 **BloodRayne: Terminal Cut**의 완전 한국어화 패치입니다.  
본 패치는 인게임 텍스트 100% 번역은 물론, **영어 대사 기반 자막**과 **일본어 대사 기반 자막**의 듀얼 스크립트를 최초로 구현하였으며, 원클릭으로 음성과 자막을 자유롭게 조합할 수 있는 **4대 통합 언어 선택기 GUI**를 기본 탑재하고 있습니다.

| 모드 | 음성 언어 | 자막 스타일 | 특징 및 추천 대상 |
| :---: | :---: | :---: | :--- |
| **모드 1** | **영어 음성** | **영어 기반 한글자막** | **[기본값 / 강력 추천]** 북미 원작의 거칠고 매력적인 오리지널 분위기를 그대로 즐길 수 있는 정통 모드 |
| **모드 2** | **일본어 음성** | **일본어 기반 한글자막** | **[강력 추천]** 일본 유명 성우진의 열연과 캐릭터성(말투/호칭)이 한글 자막과 100% 일치하는 애니메이션/콘솔 감성 모드 |
| **모드 3** | **일본어 음성** | **영어 기반 한글자막** | 박진감 넘치는 일본어 더빙을 감상하면서 자막은 원작 영문 대사 번역으로 읽는 하이브리드 모드 |

## 🛠️ '음성_언어_선택기' 상세 사용법

```
[게임 설치 폴더]
  ├── rayne1.exe (게임 실행 파일)
  ├── 음성_언어_선택기.exe  <-- GUI 선택기 실행
  ├── 음성_언어_선택.bat   <-- 배치 실행기 (더블 클릭 가능)
  └── ...
```

1. **실행 전 주의사항**:
   - 게임이 실행 중일 때는 파일이 잠겨 변경이 실패할 수 있습니다. **반드시 게임을 종료한 상태**에서 실행하세요.
2. **실행 방법**:
   - 게임 폴더 내의 **`음성_언어_선택기.exe`** 또는 **`음성_언어_선택.bat`**을 더블 클릭합니다.
3. **사용 방법**:
   - **원클릭 추천 프리셋**: 상단의 4개 버튼 중 원하는 모드(`[1]` ~ `[4]`)를 누르면 즉시 음성 바이너리, 영상, 자막이 자동으로 일괄 적용됩니다.
   - **사용자 정의 개별 선택**: 하단에서 음성(영어/일본어)과 자막(영어식/일본식)을 각각 라디오 버튼으로 고른 후 **`[★ 개별 선택 설정 적용하기]`** 버튼을 클릭합니다.
4. **적용 완료**:
   - "설정이 완료되었습니다" 팝업이 뜨면 프로그램을 닫고 스팀에서 평소처럼 게임을 시작하시면 됩니다.

## 📦 설치 방법

### [방법 1] 간편 자동 설치 (권장)
1. 릴리즈 페이지에서 다운로드받은 압축 파일의 압축을 풉니다.
2. **`한글패치_설치.bat`** 파일을 더블 클릭하여 실행합니다.
3. 스팀 설치 경로를 자동 감지하여 패치 파일 복사 및 환경설정(`rayne1.ini`) 구성을 자동으로 완료합니다.
4. 설치 완료 메시지가 나타나면 스팀 라이브러리에서 게임을 실행합니다.

### [방법 2] 수동 설치
1. 스팀 라이브러리에서 **BloodRayne: Terminal Cut** 우클릭 ➔ **[관리]** ➔ **[로컬 파일 탐색]** 클릭.
2. 패치 압축 파일 내 모든 파일/폴더(`JAPANESE.POD`, `JAPANESE_EN.POD`, `JAPANESE_JP.POD`, `video`, `음성_언어_선택기.exe` 등)를 게임 설치 폴더에 덮어씁니다.
3. 내 문서의 게임 설정 파일을 엽니다.
   - 경로: `%USERPROFILE%\Documents\BloodRayne1\settings\rayne1.ini`
4. 메모장으로 열어 아래 두 항목을 수정/추가한 후 저장합니다.
   ```ini
   [game]
   language=JP

   [Graphics]
   subtitleMode=1
   ```
5. 게임을 실행합니다.

## ⚠️ 문제 해결 및 FAQ

> **Q. 게임 내 자막이 `????`로 출력됩니다.**  
> A. 메인 설정 파일(`rayne1.ini`)의 `language=JP` 설정이 올바르게 되어 있는지 확인하세요. 본 패치는 DBCS 한글 폰트를 일본어 슬롯(`JP`)에 매핑하여 출력하므로 게임 언어가 `JP`로 지정되어 있어야 한국어가 정상 출력됩니다.

> **Q. 동영상 시네마틱 컷씬에서 자막이 나오지 않습니다.**  
> A. 게임 내 옵션 또는 `rayne1.ini` 파일에서 `subtitleMode=1`로 설정되어 있는지 확인하세요. 시네마틱 영상은 1080p Bink 고화질 한글 자막 영상으로 교체 제공됩니다.

> **Q. 음성/자막 선택기 실행 시 오류가 납니다.**  
> A. 게임(`rayne1.exe`)이 백그라운드에서 실행 중이지 않은지 확인하고, 게임을 완전히 종료한 후 관리자 권한으로 실행해 주시기 바랍니다.
